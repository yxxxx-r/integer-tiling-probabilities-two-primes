# Exact Tiling Probabilities for Prime-Power and Two-Prime-Power Cardinalities

The Python code computes the exact limiting probability that a uniformly chosen set of a given size in a growing integer interval tiles the integers by translation.

[Download the code and reference data (v1.0.0, ZIP)](https://github.com/yxxxx-r/integer-tiling-probabilities-two-primes/releases/download/v1.0.0/paper1_tiling_code_20261105.zip)

## Quick start

Extract the ZIP file, open a terminal in the `paper1` folder, and run the following command with Python 3.11 or later:

```sh
python calculate.py 6
```

The `delta_m` column gives the exact probability `937/52514`. For instructions on reproducing the other examples and running the verification scripts, see `paper1/README.md` inside the archive.
